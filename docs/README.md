# **Название проекта**

## Описание
Данный документ содержит подробное описание функционала, технических нововведений и инструкций по настройке инструментов разработки для проекта «Интернет-магазин» (альфа-версия).

## Нововведения и функции:

### 🆕 Нововведения для пользователей
* **Актуальность данных:** Пользователи всегда видят свежую информацию, так как данные в системе автоматически синхронизируются и обновляются каждый час.
* **Удобный просмотр каталога:** Структурированное отображение товаров/услуг благодаря предварительной обработке и очистке данных.
* **Быстродействие:** Оптимизированные запросы к базе данных обеспечивают быструю загрузку страниц и отклик интерфейса.

### ⚙️ Нововведения технические (не предназначенные для глаз пользователя)
* **Автоматизация обновлений:** Интеграция библиотеки `schedule` для фонового ежечасного обновления таблиц в базе данных PostgreSQL без участия человека.
* **Надежное хранение данных:** Переход на СУБД PostgreSQL с использованием драйвера `psycopg2` для безопасного и масштабируемого хранения информации.
* **Продвинутая обработка Excel:** Использование связки `pandas` и `openpyxl` для автоматического чтения, валидации и импорта данных из файлов формата `.xlsx`.
* **Обогащение данных:** Интеграция с внешними API (например, Dadata) через библиотеку `requests` для автоматической проверки, стандартизации и дополнения входящих данных (адреса, реквизиты и т.д.).
* **Система логирования:** Внедрение модуля `logging` для фиксации всех важных событий, ошибок и процессов обновления БД, что критически важно для отладки и мониторинга.
* **Строгий контроль качества кода:** Настройка и обязательное использование инструментов `flake8`, `mypy`, `black` и `isort` для обеспечения типизации, читаемости и единого стиля кода.
* **Надежное тестирование:** Покрытие кода юнит-тестами с использованием `pytest`, `Mock` и `patch` для изолированной проверки каждой функции.

*Дальнейшие функции будут описаны в последующих обновлениях.*

## **Примечание к функциям**
Все автоматические обновления происходят в фоновом режиме. В случае сбоя при загрузке данных из Excel или API, система запишет ошибку в лог-файл и продолжит работу, не прерывая основной процесс.

## Инструкция по настройке линтеров для данного проекта

Создайте файл с названием `.flake8` и в нём введите следующие настройки:
```ini
[flake8]
max-line-length = 119
ignore = E402, E251, E203
exclude = .git, .venv, __pycache__, venv
```
Вводите в файл pyproject.toml, если там не прописано, то пропишите следующие.
```
[tool.black]
# Максимальная длина строки
line-length = 119
# Файлы, которые не нужно форматировать
exclude = '''
(
  /(
      \.eggs         # Исключить несколько общих каталогов
    | \.git          # в корне проекта
    | \.hg
    | \.mypy_cache
    | \.tox
    | \.venv
    | dist
  )/
  | foo.py           # Также отдельно исключить файл с именем foo.py
                     # в корне проекта
)
'''


[tool.isort]
# максимальная длина строки
line_length = 119


[tool.mypy]
disallow_untyped_defs = true
warn_return_any = true
ignore_missing_imports = true
exclude = "venv"

```
И все зависимости что есть на данный момент будут прописаны.
